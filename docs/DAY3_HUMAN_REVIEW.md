# Day 3 — human review checklist

## Purpose
Provide a consistent review aid for the areas automation cannot reliably certify before any publication decision.

## Checklist
- Visual relevance and story continuity
- Mobile text legibility
- Audio and narration clarity
- Audience dignity and sensitivity
- Factual and product-claim accuracy
- Practical value and payoff
- Source rights and attribution
- Brand consistency

## Data behavior
A fresh checklist is added to each generated package with all items pending and decision pending. This is metadata for the reviewer, not a completed review. It does not grant approval, block generation, or change the existing publishing gate.

## Decisions
- pending
- approved
- needs_revision
- rejected

## Safeguards
Review must be completed by a human. Review metadata is not an automated legal clearance, fact check, audio inspection, or approval.
